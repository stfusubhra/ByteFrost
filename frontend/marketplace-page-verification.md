# Marketplace page verification

The KisanSetu Marketplace route is present and renders the expanded page at `/marketplace`. Desktop shows the full marketplace hero, farmer/buyer actions, supply summary metrics, search/sort/filter controls, and the beginning of the listing area. Mobile preserves the hero hierarchy, both primary actions, the three key metrics, demo-state note, and search control without clipping. The route is part of the existing public shell and the current implementation includes listing detail, filter, sort, and inquiry states.
